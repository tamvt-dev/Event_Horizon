## Visual Metaphors

### Core Concepts

#### 1. Event Horizon (Physics)
```
    ║    Light escapes
────╬────────────────  ← Event Horizon
    ║    No escape
  Black Hole
```
**Meaning**: Point of no return in graph traversal - once a beam path commits to a branch, it follows to completion.

#### 2. State Collapse (Quantum Mechanics)
```
Superposition:        Collapsed State:
  [▢▢▢▢▢▢]     →          [■]
   Multiple              Single
  possibilities          outcome
```
**Meaning**: Graph nodes collapse from multiple possible states to single averaged state (O(N²) → O(N)).

#### 3. Neuroplasticity (Biology)
```
Original Graph:       After Mutation:
    A                     A
   ╱ ╲                   ╱│╲
  B   C        →        B M C
                     (New mutant node M)
```
**Meaning**: Graph evolves and spawns new nodes based on feedback, like biological neural networks.
